## 1. Objectives
Enhance the File Menu UX with clear feedback and a dynamic list of save slots.
- **Feedback**: Display a status message after every file operation (e.g., "Saved!", "Loaded test_v1").
- **Dynamic Listing**: Automatically scan the user's save directory and display available slots in the UI.
- **Improved Load UX**: Instead of typing a name to load, users can select a slot from a list.
- **Delete Project**: Add ability to remove existing save slots from the user profile.

## 2. Component Updates

### A. Layout Update (`projects/user/layouts/file_menu.chtpm`)
- Add a `${file_response}` variable to display status messages.
- Add a `${save_slots_list}` variable to display the list of found saves.
- Add a `[5] Delete` button.
- Format the layout to accommodate these new fields.
- Ensure `${current_project}` matches manager's internal `project_id`.

### B. Manager Update (`projects/user/manager/file_manager.c`)
- **Feedback**: After calling `run_op`, update a `file_response` variable in `state.txt`.
- **Directory Scanning**:
    - Add a function to scan `projects/user/pieces/profiles/<user>/saves/<project_id>/`.
    - If slots are found, generate `<button>` strings for each slot.
- **Selection Logic**:
    - Map slots to keys 10-14.
- **Delete Logic**: Implement handler for key 5.

### C. Backend Update (`projects/user/ops/file_op.c`)
- Add `delete` command (uses `rm -rf` on the slot directory).

## 3. Implementation Steps
1. Modify `file_menu.chtpm` to include placeholders for response and slot list.
2. Update `file_manager.c` to:
    - Perform a directory scan on startup and after every save.
    - Populate `${save_slots_list}` with interactive buttons.
    - Clear the "Name" buffer after a successful "Save As".
    - Handle new key mappings for slot selection.
3. Recompile `file_manager.c`.

## 4. Verification
1. Open File Menu.
2. Verify "No saves found" (or existing saves) is displayed.
3. Perform "Save As" -> "test_v1".
4. Verify feedback message "File: save test_v1" appears.
5. Verify "test_v1" now appears in the list of slots.
6. Select "test_v1" and click "Load".
7. Verify successful load.
