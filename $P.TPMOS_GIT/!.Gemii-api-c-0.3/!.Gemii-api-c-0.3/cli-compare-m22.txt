# CLI Agent Comparison: TPMOS vs. Gemini/Qwen-CLI (May 22, 2026)

## 1. Context & RAG Capabilities
- **Gemini-CLI / Qwen-CLI:** Often include a "Context Manager" that can automatically ingest entire directories or use vector embeddings (RAG) to find relevant snippets. 
- **TPMOS Aida:** Relies on `/scan` (manual snapshot injection) and `/summarize` (manual condensation). 
- **TPMOS Gap:** Could benefit from a background "Watcher" Op that maintains a `codebase_index.json` or `project_map.txt` for automatic context injection when a specific Piece is targeted.

## 2. Token-Efficient Editing
- **Gemini-CLI / Qwen-CLI:** Typically use "Search & Replace" blocks or "Whole File" rewrites. High-end tools like `aider` use Unified Diff formats which are significantly more token-efficient.
- **TPMOS Aida:** Uses `edit_file` with exact block matching. This is safe but brittle; a single character mismatch in the search block causes failure.
- **TPMOS Gap:** Implementation of a `patch_file` tool that handles line-offset fuzzy matching (like `patch` or `git apply`) would make the agent much more robust at editing large files without needing 100% exact matches.

## 3. Auto-Validation & Linting
- **Gemini-CLI / Qwen-CLI:** Often run a test command automatically after an edit and feed the error back to the agent.
- **TPMOS Aida:** Currently requires the user to manually check or provide feedback.
- **TPMOS Gap:** A "Validation Hook" in the Manager's `ACTING` state could run `./button.sh compile` or a project-specific `test.sh` and automatically append the output to `context.json` if a failure is detected.

## 4. Multi-File Atomic Operations
- **Gemini-CLI / Qwen-CLI:** Can propose changes across 5-10 files in a single turn.
- **TPMOS Aida (Manager version):** The current C manager handles tools sequentially and often loops back to the LLM for every single tool result. 
- **TPMOS Gap:** The `gemini_payload_builder` and manager loop could be updated to allow the LLM to call a "batch" of tools (Parallel Tool Calling) before requiring a new prompt, reducing API latency and costs.

## 5. Architectural Awareness
- **Gemini-CLI / Qwen-CLI:** Sometimes read a `PROJECT.md` or `ARCHITECTURE.pdl` to understand high-level intent.
- **TPMOS Aida:** Is uniquely powerful here because it *already* lives in a PIECE/MODULE structure.
- **TPMOS Advantage:** Aida can navigate the `project.pdl` and `state.txt` of any Piece, giving it a "structural soul" that standard CLI wrappers lack.

## 6. Summary of Missing "Power" Tools:
1. **`patch_file`**: For fuzzy line-based editing.
2. **`code_index`**: For semantic/keyword lookup across large projects.
3. **`test_hook`**: For auto-detecting and auto-fixing compilation errors.
4. **`multi_call`**: For handling multiple tool demands in one pulse.
