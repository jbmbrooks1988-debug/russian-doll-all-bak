# Contemporary File Modification Plan: Reusable File Browser for TPMOS

## 1. Objectives
Transition the `agy-text-editor` from the simple slot-based saving system to a traditional workspace directory/file navigator. The updated system will allow:
- **Save**: Directly write the current document content to the active file path.
- **Save-As**: Specify a target path using a text input field, with path autocomplete dropdown choices.
- **Load File**: Browse the directory tree, navigate subdirectories, step back to parent directories via a `[..] Up` button, and select a file to open.
- **Search/Filter**: Filter directory listings in real-time using a case-insensitive search input field.

## 2. Directory Navigation & Search Design
The manager daemon will track the current directory path (e.g. starting at `projects/agy-text-editor`).
- **Current Directory Display**: A header showing the current directory path.
- **Search Field**: A `<cli_io id="search_query" />` field to accept typing. The manager reads this value (prefix `s` from `cli_buffers.txt`) and dynamically filters files and directories.
- **Directory Listing**:
  - Subdirectories are listed as selectable buttons (e.g., `[ folder/ ]`). Clicking a directory navigates down into it.
  - Files are listed as selectable buttons (e.g., `[ file.txt ]`). Clicking a file selects it, updating the target file path.
  - If the directory has a parent, a `[..] Up` button is shown at the top of the list to navigate up one level.
- **Parser Compatibility**: The manager must NOT put actual `\n` characters inside dynamic markup blocks (`directory_browser_markup`, `editor_content`, `autocomplete_suggestions_markup`) in `gui_state.txt`. Instead, it uses `<br/>` for spacing and outputs them as a single line. This prevents the CHTPM parser's `load_state_file()` from truncating them.

## 3. Path Completion & Autocomplete Dropdown
For custom path entry in Save-As/Load:
- An input text field `<cli_io id="file_path_input" />` is provided for the user to type path prefixes (prefix `f`).
- The manager reads the typed input prefix, scans the current directory, and filters matching entries.
- Clickable autocomplete choices are presented. Clicking a choice sets the path value.

## 4. Layout Architecture
We will update/create the layouts:
- **`projects/agy-text-editor/layouts/file_menu.chtpm`**:
  - Displays the current active file.
  - Buttons: `[1] SAVE`, `[2] SAVE AS`, `[3] LOAD FILE`, `[4] CANCEL`.
- **`projects/agy-text-editor/layouts/file_browser.chtpm`**:
  - Displays `Current Dir: ${browser_current_dir}`.
  - Displays search input: `<cli_io id="search_query" label="${search_query_val}" />`.
  - Displays file selection input field: `<cli_io id="file_path_input" label="${file_path_input_val}" />`.
  - Displays path completion autocomplete suggestions: `${autocomplete_suggestions_markup}`.
  - Renders the directory tree browser list: `${directory_browser_markup}`.
  - Action buttons: `${browser_action_buttons_markup}`.

## 5. Manager Code Updates (`agy-text-editor_manager.c`)
- Track state variables:
  - `char current_dir[MAX_PATH]`
  - `char active_file_path[MAX_PATH]`
  - `char file_path_input_buffer[MAX_LINE]`
  - `char search_query_buffer[MAX_LINE]`
- Real-time directory filtering:
  - Case-insensitive substring match (`strcasestr`) of directory/file names with `search_query_buffer`.
- Command processors:
  - `SET_DIR:<path>`: Updates `current_dir`, clears search query.
  - `LOAD_FILE:<path>`: Loads document, transitions back to editor.
  - `SET_INPUT_PATH:<path>`: Sets input buffer path.
  - `AUTOCOMPLETE:<completed_path>`: Completes input path.

## 6. Verification
- Open the text editor, add lines of text.
- Go to File Menu -> Load. Browse directories, check that `..` moves up and directory names move down.
- Verify directory contents are displayed.
- Type in the Search field, verify listing filters down.
- Select a file, verify it loads.
- Save As to a custom path, verify file creation.
