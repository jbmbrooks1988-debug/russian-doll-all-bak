     1. Arrow Keys (MSYS2/mintty) - Physical arrow keys don't work
        in MSYS2 bash terminal

        - Workaround: Use number keys (1-9) for navigation

        - Root cause: Linux uses /dev/input/js0 (doesn't exist on
          Windows)
        - Required: XInput API or DirectInput for Windows gamepad
          support

        - Status: Needs separate Windows implementation
