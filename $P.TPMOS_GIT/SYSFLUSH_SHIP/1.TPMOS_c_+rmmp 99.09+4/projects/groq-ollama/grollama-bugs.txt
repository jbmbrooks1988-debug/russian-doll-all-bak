# GROQ-OLLAMA Integration Bugs & Investigation
**Date:** 2026-05-13
**Author:** Gemini Agent

## 1. Symptom: Silence & Blank UI
The integrated manager launches but the UI remains blank (variables like `${ai_state}` are empty) and no response is generated even after hitting Enter.

## 2. Bug: Input Key Mismatch
- **Observation:** `cat gui_state.txt` revealed `input_text=how are you?`.
- **Code:** `groq-ollama_manager.c` was looking for `groq-ollama_input`.
- **Cause:** The TPMOS parser defaults `cli_io` buffers to `input_text` in many layouts, or there's a hardcoded mapping.
- **Fix:** Change manager to look for `input_text`.

## 3. Bug: State Overwrite (The "Wipe" Bug)
- **Observation:** Manager writes full state to `gui_state.txt` with `fopen(..., "w")`. Parser writes input updates to the SAME file.
- **Conflict:** If the parser writes a single line `input_text=...`, it wipes the rest of the file (ai_state, resp_area, etc.). This explains why the UI variables appear blank in the frame—the manager writes them, but the parser's next keypress wipe them out.
- **Fix:** Manager must read existing `gui_state.txt`, merge its projection, and write back. Or use separate files for input vs. projection (preferred in TPMOS).

## 4. Bug: Manager Execution State
- **Observation:** Manager was not in `proc_list.txt` or `ps aux`.
- **Cause:** Likely exited due to an error or was never successfully backgrounded by the loader.
- **Fix:** Ensure `run.sh` backgrounds the manager or the loader is configured correctly. For debugging, run in a separate terminal.

## 5. Bug: Context Percentage Calculation
- **Code:** `ctx_divisor` is defined but unused. The UI shows `??` for `ctx_pct`.
- **Fix:** Implement the length-based calculation used in `agent.c`.

## 7. Verification Results (SUCCESS)
- **Input Sync:** Manager correctly detects `input_text` and triggers the AI pulse.
- **State Merging:** `update_ui_vars` successfully preserves the input buffer while refreshing projection variables (`ai_state`, `ctx_pct`, etc.).
- **LLM Pulse:** Real round-trip to Ollama confirmed. Response area correctly displays the wrapped text.
- **Context Stats:** Dynamic calculation is live (e.g., `3%` for simple greeting).

**Status:** ALL CRITICAL BUGS RESOLVED. Project is stable.
