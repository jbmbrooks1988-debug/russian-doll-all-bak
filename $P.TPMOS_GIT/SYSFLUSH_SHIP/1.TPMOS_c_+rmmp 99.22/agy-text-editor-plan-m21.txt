# agy-text-editor Plan (M21)
# Create a Simple Text Editor Project with Save/Load in TPMOS

## 1. Objective
Build a lightweight text editor (`agy-text-editor`) inside the `projects/` directory of TPMOS. The main purpose is to implement and verify the file save/load checkpoint feature set, mirroring the pattern designed for `op-ed` using the `file_op.+x` system tool.

---

## 2. Architecture & Design

### A. The Piece State (Sovereign Data)
- The text file being edited is stored in `projects/agy-text-editor/pieces/document.txt`.
- When editing, the manager appends lines to or clears this file.
- Saving/loading will clone the entire `pieces/` directory (including `document.txt`) to/from versioned slots using the core `file_op.+x` system tool.

### B. Directory Topology
```
projects/agy-text-editor/
├── project.pdl              # Project metadata & entry layout mapping
├── pieces/
│   └── document.txt         # Sovereign edited file content
├── layouts/
│   ├── editor.chtpm         # Main text editor display & controls
│   ├── file_menu.chtpm      # Save, Load, and slot management links
│   └── load_slot.chtpm      # Browse & select save slots
└── manager/
    └── agy-text-editor_manager.c  # Daemon running the main input-output loop
```

---

## 3. Detailed Component Designs

### A. project.pdl
Declares project metadata and maps `entry_layout` to `projects/agy-text-editor/layouts/editor.chtpm`.

### B. UI Layouts (CHTPM files)
1. **editor.chtpm**:
   - Displays the current content of `document.txt` using dynamic state variable `${editor_content}`.
   - Text input field `<cli_io id="editor_line" label="${input_line}" />`.
   - Action buttons:
     - `[1] Append Line` (sends `KEY:1` -> appends text buffer to `document.txt`).
     - `[2] Clear File` (sends `KEY:2` -> empties `document.txt`).
     - `[3] File Menu` (redirects to `file_menu.chtpm`).
2. **file_menu.chtpm**:
   - Options:
     - `[1] Save to Slot` (sends `KEY:7` -> runs save to selected slot name).
     - `[2] Browse Slots` (redirects to `load_slot.chtpm`).
     - `[3] Back to Editor` (redirects to `editor.chtpm`).
   - Dynamic status message `${editor_response}`.
3. **load_slot.chtpm**:
   - Displays slot selection buttons via `${slot_selection_markup}` dynamically populated by `file_op.+x list`.
   - Clicking a slot button runs `SET_SLOT:<name>` which calls `file_op.+x load` and returns to `editor.chtpm`.

### C. Manager Daemon (`agy-text-editor_manager.c`)
- Reads path locations from `pieces/locations/location_kvp`.
- Monitors `/pieces/apps/player_app/history.txt` for keypresses and custom commands.
- Handles commands:
  - `KEY:1`: Appends text from `pieces/apps/player_app/cli_buffers.txt` (input field `editor_line`) to `document.txt`.
  - `KEY:2`: Clears `document.txt`.
  - `KEY:7`: Performs save using `file_op.+x save agy-text-editor <slot_name>`.
  - `SET_SLOT:<name>`: Performs load using `file_op.+x load agy-text-editor <name>` and redirects layout back to `editor.chtpm`.
- Publishes UI variables to `projects/agy-text-editor/manager/gui_state.txt`.

---

## 4. Build & Compile Cycle
1. Run `./button.sh compile` to compile all project managers including `agy-text-editor_manager.c`.
2. Confirm compilation creates `projects/agy-text-editor/manager/+x/agy-text-editor_manager.+x`.

---

## 5. Verification Plan
1. Switch to `agy-text-editor` in the project loader menu.
2. Type text in the editor, click "Append Line" and check that it displays.
3. Navigate to File Menu -> Save to Slot (with default/custom slot name).
4. Clear the text document.
5. Navigate to File Menu -> Browse Slots -> Select the slot.
6. Verify document text is successfully loaded back.
