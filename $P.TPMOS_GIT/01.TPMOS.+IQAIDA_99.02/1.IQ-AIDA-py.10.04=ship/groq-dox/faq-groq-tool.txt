## 1. The "Ultimate" grok-cli.py
This version adds a shell executor (be careful with this one!) so it can run things like ls -la or pip install directly if you ask.

import ollamaimport osimport subprocess
# --- THE HANDS (ACTUAL FUNCTIONS) ---def write_file(filename, content):
    with open(filename, 'w') as f: f.write(content)
    return f"Done: Wrote to {filename}"
def read_file(filename):
    try:
        with open(filename, 'r') as f: return f.read()
    except Exception as e: return f"Error: {str(e)}"
def run_command(command):
    """Allows the model to run bash commands directly."""
    try:
        result = subprocess.run(command, shell=True, capture_output=True, text=True)
        return f"STDOUT: {result.stdout}\nSTDERR: {result.stderr}"
    except Exception as e: return str(e)
# --- THE BRAIN CONFIG ---tools = [
    {'type': 'function', 'function': {'name': 'write_file', 'description': 'Write text to a file', 'parameters': {'type': 'object', 'properties': {'filename': {'type': 'string'}, 'content': {'type': 'string'}}, 'required': ['filename', 'content']}}},
    {'type': 'function', 'function': {'name': 'read_file', 'description': 'Read a file content', 'parameters': {'type': 'object', 'properties': {'filename': {'type': 'string'}}, 'required': ['filename']}}},
    {'type': 'function', 'function': {'name': 'run_command', 'description': 'Run a bash/shell command', 'parameters': {'type': 'object', 'properties': {'command': {'type': 'string'}}, 'required': ['command']}}}
]
# Persistent conversation historymessages = [{'role': 'system', 'content': 'You are a helpful coding assistant with access to the file system and shell. Use tools whenever the user asks to perform an action.'}]

print("\033[94mGrok-CLI (Llama-3-Groq-Tool-Use) Active.\033[0m")
while True:
    user_input = input("\033[92m>> \033[0m")
    if user_input.lower() in ['exit', 'quit']: break
    
    messages.append({'role': 'user', 'content': user_input})
    
    # The Loop: Allows the model to call multiple tools in a row
    while True:
        response = ollama.chat(model='llama3-groq-tool-use', messages=messages, tools=tools)
        
        # If the model wants to talk instead of act
        if not response.message.tool_calls:
            print(f"\n{response.message.content}\n")
            messages.append(response.message)
            break
            
        # If the model wants to use tools
        messages.append(response.message) # Record the intent to use a tool
        for tool in response.message.tool_calls:
            name = tool.function.name
            args = tool.function.arguments
            
            print(f"\033[90m[Executing {name} with {args}...]\033[0m")
            
            # Map name to function
            if name == 'write_file': result = write_file(**args)
            elif name == 'read_file': result = read_file(**args)
            elif name == 'run_command': result = run_command(**args)
            
            # Feed the result back to the model
            messages.append({'role': 'tool', 'content': result, 'name': name})

## 2. Make it a Global Command
If you want to run it from anywhere just by typing grok, do this:

   1. Add a "shebang" to the very top of your script:
   
   #!/usr/bin/env python3
   
   2. Make it executable:
   
   chmod +x grok-cli.py
   
   3. Alias it in your .bashrc or move it to /usr/local/bin:
   
   sudo cp grok-cli.py /usr/local/bin/grok
   
   
Now you can just type grok in any folder.
Warning: Since I added run_command, the model can technically run rm -rf /. It usually won't unless you tell it to, but be aware it now has "Sudo-lite" powers over your current directory!

Since you want this to be a powerhouse like Qwen-Coder or Aider, here are the three biggest "modern" features you’re currently missing that would make this a pro-grade tool:
## 1. Code Editing (The "Search & Replace" Block)
Right now, if you want to change one line in a 100-line script, the AI has to rewrite the entire file. Modern tools use a "diff" or "replace" function.

* The Power: You can tell it "Change the database password in config.py" and it only swaps that one line instead of dumping 500 lines of text back into your terminal.

## 2. Context Window Management (The "Memory" Problem)
LLMs have a limit. If you keep chatting for an hour, or if you ask it to read a massive log file, the "conversation history" will eventually get too big and the model will start "forgetting" the beginning or crashing.

* The Power: Adding a simple "summarizer" or a "clear history" command (/clear) to keep the brain sharp.

## 3. File Search (The "RAG" Lite)
If you're in a big folder with 50 files, the AI doesn't know which one contains your main() function unless you tell it.

* The Power: A grep or search_files tool that lets the AI "look for keywords" across the whole directory so it can find where a bug is hiding without you pointing to the exact file.

## 4. Image/Vision Support (If using a Multimodal Model)
If you ever switch the model to pixtral or llama3.2-vision in Ollama, you could add a tool to "look" at a screenshot of a bug and have it write the fix.
