# Save-As Pipeline Study: agy-text-editor

## 1. Trigger
- User presses '8' (Save As) or '7' (Save) when no active file is set.
- Manager sets `browser_mode = 1`.
- Transition to `file_browser.chtpm`.

## 2. Input
- User can type into `file_path_input` (mapped to `f` prefix in `cli_buffers.txt`).
- Autocomplete suggestions provide clickable buttons with `AUTOCOMPLETE:<path>` or `SET_INPUT_PATH:<path>`.
- `AUTOCOMPLETE` and `SET_INPUT_PATH` both call `set_file_path_input()`, which writes to `cli_buffers.txt` and updates the manager's `file_path_input_buffer`.

## 3. Action Execution
- User clicks "SAVE FILE" button which sends `SAVE_AS_ACTION`.
- `handle_command("SAVE_AS_ACTION")` calls:
    1. `read_file_path_input()`: Syncs `file_path_input_buffer` from `cli_buffers.txt`.
    2. `save_to_path(file_path_input_buffer)`:
        - Resolves `full_path` using `project_root` and `current_dir`.
        - Opens `projects/agy-text-editor/pieces/document.txt` (Working Buffer) for READ.
        - Opens `full_path` (Target) for WRITE.
        - Copies content byte-by-byte.
        - Updates `active_file_path`.
        - Updates `response_buffer`.

## 4. UI Refresh
- `update_gui_state()` is called.
- It writes `active_project=%s` and `editor_map=%s` to `gui_state.txt`.
- `trigger_render()` is called, waking up the Parser.

## 5. Reverse Engineering for LOAD
Current `load_from_path` does:
- Opens `full_path` (Source) for READ.
- Opens `projects/agy-text-editor/pieces/document.txt` (Working Buffer) for WRITE.
- Copies content byte-by-byte.
- Updates `active_file_path`.
- Calls `load_document_to_buffer()` (reads Working Buffer into memory `document_lines`).
- Resets cursor.

```c
static void load_document_to_buffer(void) {
    char doc_path[MAX_PATH];
    snprintf(doc_path, sizeof(doc_path), "%s/projects/agy-text-editor/pieces/document.txt", project_root);
    FILE *f = fopen(doc_path, "r");
    total_lines = 0;
    if (f) {
        while (fgets(document_lines[total_lines], MAX_LINE, f) && total_lines < 99) {
            char *nl = strchr(document_lines[total_lines], '\n');
            if (nl) *nl = '\0';
            nl = strchr(document_lines[total_lines], '\r');
            if (nl) *nl = '\0';
            total_lines++;
        }
        fclose(f);
    }
    if (total_lines == 0) {
        strcpy(document_lines[0], "");
        total_lines = 1;
    }
}
```
