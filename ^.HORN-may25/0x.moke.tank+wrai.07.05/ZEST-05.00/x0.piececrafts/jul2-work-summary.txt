THEORY (Most Likely Problem)
================================================================================

Wraith-alpha's parser may only read its OWN gui_state.txt, not child
projects' state files. This would explain why:

  - Manager IS running (proven by debug_log.txt)
  - Manager IS updating state (proven by state.txt changes)
  - But layout shows nothing (variables not available to parser)

SOLUTION PATH:
  1. Confirm with wraith-man-test (simpler diagnostic)
  2. If confirmed, check how Wraith exposes child state to layouts
  3. May need to modify wraith-alpha manager to read child state
     and merge it into wraith-alpha's own gui_state.txt
  4. Or create special syntax for child variable references
