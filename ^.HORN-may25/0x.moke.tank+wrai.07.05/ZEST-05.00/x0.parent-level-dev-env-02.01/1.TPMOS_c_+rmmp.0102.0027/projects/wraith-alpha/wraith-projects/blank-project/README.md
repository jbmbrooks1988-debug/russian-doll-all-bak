# Wraith Blank Project

This is the first real Wraith test project.

Purpose:
- Prove that a Wraith project can live inside the same desktop session as the shell.
- Keep save/load scoped to the whole Wraith environment.
- Preserve the nested project ID `wraith-alpha/wraith-projects/blank-project`.

Notes:
- `blank-proj` is the launcher alias.
- `Blank Project` is the user-facing window title.
- The project is intentionally minimal, but it is not a fake placeholder.
- The window uses the same standard Wraith desktop chrome and controls as every other opened project.
