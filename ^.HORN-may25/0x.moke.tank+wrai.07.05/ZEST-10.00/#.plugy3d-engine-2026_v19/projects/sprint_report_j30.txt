4. CURRENT ENTITY LOADING PATH:
   - Projects -> pieces directory -> individual .txt files OR piece_map.csv

IMPLEMENTATION GAPS IDENTIFIED:
-------------------------------

1. Missing Integration:
   - data/locations.txt file needs to be integrated with the project loading system
   - Entities should read base paths from locations.txt rather than being hardcoded

2. Incomplete Migration:
   - Hardcoded entity loading in entity_manager.py should delegate to project system
   - Locations.txt should act as base configuration for different entity types

3. PIECE LOADING PRIORITIZATION LOGIC:
   - Project Manager first checks for 'piece_map.csv' in the peices directory
   - If piece_map.csv exists, it uses that for all entities (ignoring individual .txt files)
   - If piece_map.csv does not exist, it loads individual .txt files from the peices directory
   - If no individual .txt files exist either, it creates default demo pieces
   - This means piece_map.csv has HIGHER priority than individual piece files
