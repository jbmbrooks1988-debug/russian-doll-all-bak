# Gem-Dev Tool Integration Fixes - 2026-05-26

## Issues Identified

1. **Bug in `gemini_payload_builder.c`: `parse_key_obj`**
   - The parser for extracting `name` and `args` from the context JSON's `assistant` messages was not skipping strings.
   - If an argument (like `content` in `write_file`) contained a `}` character, the parser would prematurely stop, resulting in invalid JSON.
   - **Reproduction:** Created `test_parser_bug.c` which confirmed truncation for `{"content": "}"}`.

2. **Incorrect Role for Tool Responses**
   - `gemini_payload_builder.c` was using `role: "user"` for function responses.
   - According to Gemini API specs, this should be `role: "function"`.

3. **Missing JSON Escaping in Payload Builder**
   - Many fields were being written directly using `%s` in `fprintf`, which could break the JSON if the content contained quotes or newlines.
   - While `json_state` escapes when writing to `context.json`, `gemini_payload_builder` needs to be careful when re-wrapping or unescaping.

4. **Missing Tool Handlers in Manager**
   - `gemini_payload_builder.c` declares tools like `edit_file` and `search_in_files`, but `gem-dev_manager.c` doesn't have `if/else if` blocks to handle them.

## 2026-05-26 - Tool Execution & Sandbox Analysis

### Findings
- **Sandbox Location:** All tools with `sandbox=true` execute in `projects/gem-dev/sandbox`.
- **`test_file.txt` Status:** Verified that the file WAS successfully created in the sandbox directory.
- **`list_dir` Failure Diagnosis:** 
  - The AI called `list_dir` with empty arguments `{}`. 
  - `json_parser` returned an empty string for the missing `path` key.
  - The manager passed this empty string to the `list_dir` binary.
  - `opendir("")` failed with "No such file or directory", resulting in an empty response to the AI.

### Fixes
- Updated `gem-dev_manager.c` to handle empty strings from `json_parser`.
- If a path is empty or NULL, it now explicitly defaults to `.` (the current sandbox directory).
- Added length checks for other arguments (e.g., `cmd` in `exec_cmd`) to prevent invalid executions.

### Verification
- Recompiled manager. 
- The agent should now correctly see files in the sandbox when using `list_dir`.
