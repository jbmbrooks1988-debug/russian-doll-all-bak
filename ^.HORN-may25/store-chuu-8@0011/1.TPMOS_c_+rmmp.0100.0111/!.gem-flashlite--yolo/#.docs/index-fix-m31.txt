# Bug Investigation: CHTMGL-Alpha Loading Failure
**Status:** DIAGNOSED
**Date:** May 31, 2026
**Target:** `pieces/apps/gl_os/plugins/gl_desktop.c` -> `get_pdl_value` & `execute_option`

---

## 1. Symptom
Clicking `chtmgl-alpha` in the GL-OS Project Explorer launches a "Generic Fallback" (Legacy Mirror) instead of the intended `index.chtmgl` layout.

## 2. Root Cause Analysis

### 2.1 PDL Parser Logic Error
The function `get_pdl_value` in `gl_desktop.c` has a logic flaw that makes it incompatible with "Table-Style" PDLs (where the section name is on every line).

**The Code:**
```c
if (strncmp(trimmed, section, strlen(section)) == 0 && (trimmed[strlen(section)] == ' ' || ...)) {
    in_section = 1;
    continue; // <--- BUG: This skips the line even if it contains a Key|Value
}
```
Because `chtmgl-alpha/project.pdl` uses `META | key | value`, the parser identifies `META`, sets `in_section = 1`, and then immediately **discards** the line. It never reaches the key-matching logic for that line.

### 2.2 Incomplete Probing Logic
If `get_pdl_value` fails (returning an empty string), the host attempts to "probe" for a default layout. However, it only looks for `.gltpm` extensions, ignoring the new `.chtmgl` standard.

**The Code:**
```c
snprintf(probe, sizeof(probe), "projects/%s/layouts/%s.gltpm", ...);
```
It never probes for `index.chtmgl` or `%s.chtmgl`.

### 2.3 Legacy Fallback
When both PDL lookup and probing fail, the system falls back to `create_mirrored_window`, which uses the legacy `project_mirror` type instead of the modern `gltpm_app` type.

---

## 3. Prescribed Fixes

### Fix A: Patch `get_pdl_value`
Remove the `continue` or add logic to process the line even if the section match occurs at the start.

```c
if (strncmp(trimmed, section, strlen(section)) == 0 && (trimmed[strlen(section)] == ' ' || ...)) {
    in_section = 1;
    /* Do NOT continue; allow the Key|Value logic below to run */
}
```

### Fix B: Update Probing in `execute_option`
Add `.chtmgl` to the search path for default layouts.

```c
snprintf(probe, sizeof(probe), "projects/%s/layouts/index.chtmgl", id);
if (access(abs_p, F_OK) == 0) { ... }
```

### Fix C: Prefer `gltpm_app` Fallback
Instead of `create_mirrored_window`, the fallback should attempt to open a `gltpm_app` with a "Missing Layout" template if no layout is found.

---

## 4. Verification Plan
1.  Apply Fix A and B.
2.  Launch GL-OS.
3.  Select `CHTMGL-Alpha`.
4.  Confirm `index.chtmgl` is loaded and rendered via the new structural parser.
