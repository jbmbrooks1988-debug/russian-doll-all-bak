DECISION TREE: "Where does this doc go?"
────────────────────────────────────────
1. Is it a TECHNICAL SPEC for a system component?
   → YES: #.main/ (or project folder if project-specific)
   → NO: Continue

2. Is it for PEOPLE learning/using the system?
   → YES: #.docs/
   → NO: Continue

3. Is it about FUTURE plans/roadmap?
   → YES: #.plans/
   → NO: Continue

4. Is it a SCRIPT for building/testing/maintenance?
   → YES: #.tools/
   → NO: Where did this come from?!

FILE FLOW: How Input Becomes Action (Standardized Ops)
================================================================================

1. USER INPUT → keyboard_input.+x → history.txt
2. PARSER → routes to active project buffer (project/history.txt)
3. MANAGER (Brain) → polls buffer (Stat-First Pattern)
4. MANAGER → calls OP (Muscle) via fork()/exec()
5. OP → updates piece state (state.txt)
6. STATE CHANGE → triggers pulse (frame_changed.txt)
7. RENDERER → composes view (current_frame.txt)
8. DISPLAY → prints frame to terminal/GL window

QUICK START: First-Time User Walkthrough
================================================================================

──────────────────────────

STEP 2: Run the System
──────────────────────

─────────────────────────────────

STEP 4: Discover Available Ops
──────────────────────────────
./pieces/system/fondu/fondu.+x --list-ops

TROUBLESHOOTING & MAINTENANCE
================================================================================

1. Terminal Glitched after Ctrl+C?
   → ./#.tools/fix_terminal.sh

2. Binary Missing?
   → ./#.tools/check_binaries.sh

3. CPU Running High?
   → ./#.tools/pmo_cpu_health.sh

4. Fondu Issues?
   → See Textbook v6.00 Chapter 5 (The App Factory)

5. Project not compiling?
   → Check: pieces/os/compiled_projects.txt includes the project folder name.
   → Run: ./#.tools/compile_all.sh

6. GL-OS issues?
   → See #.main/gl-os-postmortem.txt (learn from mistakes)
   → Check parser get_var() reads desktop_view from view.txt

7. Op-ed or xlector issues?
   → Check Pitfalls: #.docs/05-PITFALLS/^.pmo.ld-faq+8/PITFALLS_ACTIVE_*.txt
