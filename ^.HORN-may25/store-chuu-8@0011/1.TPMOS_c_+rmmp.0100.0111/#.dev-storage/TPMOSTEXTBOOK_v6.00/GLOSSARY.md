# 📖 TPMOS Glossary: Standardized Ops Edition
A comprehensive guide to the terminology of the Piece Method. 🏛️📜

---

### **A**
*   **Artifact:** A 3D object in GL-OS, defined by an 8x8x8 voxel mask.
*   **Atomic Swap:** The practice of writing to a `.tmp` file and using `rename()` to update state safely.
*   **Auditable:** A Piece trait that ensures all state changes are logged to the `master_ledger.txt`.

### **B**
*   **Black-Scholes:** The mathematical model used in the Financial Forge to price simulated options.
*   **Brain:** The Module layer of the PMO hierarchy (The Controller).

### **C**
*   **CHTPM:** The ASCII markup language used to define TPMOS layouts.
*   **CHTMGL:** The high-fidelity extension of CHTPM for 3D environments.
*   **Cognitive Module:** A Module that uses the AI Brain (LLM) to make decisions.
*   **Consensus:** The agreement process in P2P-NET to maintain a unified global state.

### **D**
*   **DNA (.pdl):** The permanent metadata that defines what a Piece *is*.
*   **Data Sovereignty:** The principle that a Piece owns its state exclusively and locally.

### **E**
*   **Exo-Sovereignty:** The ability of a TPMOS node to function without external internet dependencies.
*   **Extrusion:** The process of pushing a 2D ASCII character into the Z-axis to create a 3D Artifact.

### **F**
*   **Fondu:** The project lifecycle manager (install, uninstall, register ops).
*   **Fuzz-Op:** The chaos-testing utility that stress-tests Standardized Ops.

### **G**
*   **Gem-API:** The standardized interface for connecting TPMOS to Large Language Models.
*   **Global Ops Catalog:** The centralized phonebook (`ops_catalog.txt`) of all available system capabilities.

### **L**
*   **Leader Election:** The process of choosing a "Ring Master" in a P2P-NET mesh.

### **M**
*   **Mirror (state.txt):** The transient, file-based reflection of a Piece's current state.
*   **Muscle:** The Op layer of the PMO hierarchy (The Execution).

### **O**
*   **Op (Standardized Op):** A standalone C binary that performs a single, atomic action.

### **P**
*   **PAL (Prisc Assembly Language):** The scripting language used to orchestrate complex Op workflows.
*   **Piece:** The atomic unit of the TPMOS ecosystem.

### **S**
*   **Soul Pen:** The suite of tools for generating lore and AI-driven creativity.
*   **Standardized Ops:** The v6.00 architecture where all actions are registered and interoperable.

### **T**
*   **Thin Brain:** A design pattern where a Module delegates all logic to Ops.
*   **Theater:** The rendering layer of the PMO hierarchy (The View).
*   **TSOTS-ONLINE:** The Sovereign Online—the decentralized identity and mesh layer.

### **Y**
*   **Yahoo Project:** The real-time financial data integration for TPMOS.
