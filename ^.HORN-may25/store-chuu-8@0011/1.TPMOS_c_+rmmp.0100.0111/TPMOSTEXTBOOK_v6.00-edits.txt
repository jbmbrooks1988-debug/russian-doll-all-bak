CH19: THE THEATER (CHTPM MARKUP & PARSER)
*   **The Syntax of Reality**: In-depth look at `pieces/chtpm/plugins/chtpm_parser.c`.
    - Tag Specs: 
      * `<layout>`: Root container defining the app's scope.
      * `<row>` / `<cell>`: The grid system for ASCII layout organization.
      * `<text label="..." />`: Static or variable text display.
      * `<button label="..." onClick="..." href="..." />`: The primary interaction node.
      * `<cli_io id="..." label="..." />`: User text entry (History Injection).
*   **The Variable Engine**: 
    - The `${var}` pattern: Real-time substitution from `state.txt` or `gui_state.txt`.
    - Scope resolution: How the parser searches project-local variables before global fallbacks.
*   **Optimization**: 
    - State-First Polling: Rendering ONLY on `frame_changed.txt` or `history.txt` size change.
    - Zero-Waste Pulse: How the parser keeps CPU at 0% when the user is idle.
