TPMOS/GL-OS Pre-CHTMGL Integration Report (m31)
=================================================
Date: May 31, 2026
Subject: Macro/Micro Roadmap for CHTMGL Integration & Emoji Studio Clone

1. MACRO-LEVEL: Architectural & Ecosystem Status
------------------------------------------------
Current State:
- Achieved full parity in project discovery, descriptor resolution (PDL), and launching mechanics between ASCII TPMOS and GL-OS. 
- The project loader is no longer a source of technical debt.
- System sovereignty is confirmed via the `SOVEREIGN | true` flag.

Goal:
- Achieve "UI Sovereignty" in GL-OS. Projects should not just "load" correctly, but also render their rich graphical UIs (via CHTMGL) within the sovereign bounds of the GL-OS viewport without compromising the host environment.

2. MICRO-LEVEL: Technical & Implementation Requirements
------------------------------------------------------
Current Gaps:
- **Parser Parity:** `gltpm_parser.c` is not yet capable of translating CHTML markup into the necessary `GLTPMScene` struct data.
- **Rendering:** Need to implement the `<canvas>` tag rendering pipeline in `gl_renderer.c`.
- **Interaction:** Missing the routing logic between GUI events (mouse click on canvas/button) and the underlying manager IPC.

Immediate Action Items:
- [ ] Refactor `gltpm_parser.c` to support structural CHTML tags (<window>, <panel>).
- [ ] Implement translation layer from CHTML parsed nodes to `GLTPMScene` objects.
- [ ] Connect `controller.c` event stream to `editor_manager.c` IPC handlers.

3. SHORT-TERM & LONG-TERM ROADMAP
---------------------------------

Short-Term (Bridge & PoC):
- Establish proof-of-concept `chtmgl-test` in `gl-os`.
- Port basic button/panel markup parsing.
- Validate IPC communication between the GL-OS UI and a simple TPMOS module.

Long-Term (Application Implementation):
- Integrate `#.emoji-studio-501` components.
- Enable high-performance 3D/2D rendering via `stb_image` and canvas integration.
- Implement PRISC animation scripting for live asset manipulation within the editor.
