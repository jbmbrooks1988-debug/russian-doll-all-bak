CHTPM HREF NAVIGATION FIX — COMPLETE & PROPAGATED
==================================================
Date: 2026-07-22
Status: ✅ TESTED, FIXED, PROPAGATED TO ALL PROJECTS

SUMMARY
=======

Fixed href navigation failure for buttons inside ACTIVATE menus (collapsible groups).
When users opened a menu and pressed Enter on a button with href, navigation was blocked.

ROOT CAUSE
==========

Active mode Enter key handler (chtpm_parser_pal.c lines 3381-3402) only checked for:
  1. Nested ACTIVATE buttons
  2. onClick handlers

Missing: href attribute check (present in navigation mode but not in active mode)

THE FIX (9 Lines Added)
=======================

Location: chtpm_parser_pal.c, lines 3396-3404
Code: Added href handler before onClick check in active mode Enter handler

  } else if (strlen(child_el->href) > 0) {
      strncpy(current_layout, child_el->href, MAX_PATH-1);
      cleanup_module();
      active_index = -1;
      focus_index = 0;
      parse_chtm();
      initialize_focus();
      export_active_index();
      compose_frame();
  }

This ensures href navigation works the same inside ACTIVATE menus as outside.
