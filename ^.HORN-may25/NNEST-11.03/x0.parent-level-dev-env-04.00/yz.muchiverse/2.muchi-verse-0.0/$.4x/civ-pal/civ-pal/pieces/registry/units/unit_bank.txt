# unit bank - TYPE/TEMPLATE registry, one row per unit type that can
# exist. Per MUCHI-CIV-DESIGN.txt sec. 3 (bank vs instance-dir split,
# zest-er-summary sec. 4.4): static content, never mutated at runtime.
# Unlike angler_bank.txt (angler-empires sibling project), this bank has
# NO tribe/civ column - unit TYPES are shared across every civ (any civ
# can build a Settler), a specific civ's OWNERSHIP of a spawned unit is
# instance state (civ_id in the instance's own state.txt), not bank data.
#
# Control model: same cursor-driven selection as angler-empires (direct
# user note, 2026-07-21: "this is how civilization's own control system
# works too") - NO unit here is directly, permanently "the player's
# hero." The player selects a unit/city with the free-roaming cursor
# (this project's own hero/state.txt already has xlector_pos_x/
# xlector_pos_y + interact_mode, same mechanism as fuzz-op's own
# pieces/xlector - see angler-empires' dox/ANGLER-EXPANSES-DESIGN.txt
# draft 3 correction for the full citation) and issues orders to
# whichever unit/city is currently selected - ownership (civ_id) decides
# who's allowed to select/command it, not any is_player-style flag.
#
# Format: id|name|glyph|color|category|move_range|attack|defense|
#         required_tech|build_cost
#   category: settler|worker|military (matches design doc sec. 1's own
#     era-agnostic "category, not era" column choice - later-era units
#     are new rows, not new columns).
#   required_tech: a civ_tech_bank.txt id, or "none" for starter units
#     buildable with no research (this file currently has none built
#     yet - design doc sec. 4, not built this pass).
#   build_cost: abstract production-point cost, city production queues
#     (not built yet) will read this column once they exist.
#
# First real slice per HANDOFF-4X-FAMILY.txt sec. 3.2's own
# recommendation: one civ, one planet, one city, no tech - these 3 rows
# are exactly what that slice needs and nothing more (a settler to found
# with, a worker to improve tiles, one military unit to defend/scout).
