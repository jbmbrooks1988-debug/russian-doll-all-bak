# handoff-j18.txt - XO-PET V1 PoC Handoff

## Current Status: PHASE 4+ (Simulation Functional)
The `xo-pet-v1` project is now a working proof-of-concept within the `mew` project hierarchy.

### Location:
- **Project Root**: `x0.5-liz.fiter4-mew-00.00/projects/xo-pet-v1/`
- **Tank Pieces**: `moke-pet-project-2.0/pieces/world_tank_01` (Symlinked into the project)

### Features Implemented:
1.  **Xelector Hub**:
    - Acts as a simulation controller.
    - Methods: `possess_bulb`, `possess_char`, `start_sim`, `pause_sim`.
2.  **Possession System**:
    - Clicking a possession button in the Xelector menu switches `active_target_id`.
    - Possessed pets expose their own DNA methods (`eat`, `attack`, `mate`, `release`) via dynamic buttons.
3.  **Simulation Sync**:
    - **End Turn (Key 9)**: Manually advances the simulation epoch.
    - AI-controlled lizards act automatically during the End Turn phase.
    - User-controlled lizards only run metabolism/death checks during End Turn; their main actions are driven by user buttons.
4.  **Thin Theater Projection**:
    - `manager/gui_state.txt` publishes all layout variables.
    - `layouts/xo-pet.chtpm` provides the visual interface.

### How to Run:
1.  Navigate to `x0.5-liz.fiter4-mew-00.00/projects/xo-pet-v1/`.
2.  Execute `./run_xo-pet.sh`.
3.  In the GUI:
    - Use numbers 2-5 to control the Xelector.
    - Once a pet is possessed, use 2-6 to control the pet.
    - Press 9 to advance the simulation when `sim_status=RUNNING`.

### Pending Improvements:
- **AI Turn Visualization**: Currently, AI turns happen instantly during the End Turn phase. We could add a slight delay or frame-by-frame projection of AI actions.
- **Naked Control Refinement**: Integrating the `bot-xo5` cognition to allow the pet to choose its own buttons when not under manual control.
