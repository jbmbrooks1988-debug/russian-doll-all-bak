Roadmap: Modifying 'agent.c' UI Layout to match 'gemini-cli' (Easiest to Hardest)

1. [Easiest] Basic Frame Partitioning in `refresh_ui`
   - Modify `refresh_ui` to strictly define the top-level sections (e.g., Header, Log Area, Prompt Area).
   - Use fixed line counts for these sections to ensure consistency.

2. [Easy] Robust Terminal Sizing
   - Replace or enhance `frame_clear` to use more robust `ioctl` polling for `TIOCGWINSZ`.
   - Update all rendering logic to adapt to terminal resize events (requires handling `SIGWINCH`).

3. [Moderate] Component-Based UI Rendering
   - Break `refresh_ui` into separate functions: `draw_header()`, `draw_log_area()`, `draw_prompt_area()`.
   - Implement a simple "Virtual Cursor" system to track where in the frame the cursor should be after rendering.

4. [Hard] Persistent Status Area Implementation
   - Reserve the top or bottom 2-3 lines of the terminal as a permanent status/spinner bar.
   - Prevent log output from scrolling into the status bar area, requiring logic to write logs within a sub-scrolling region of the main log area.
