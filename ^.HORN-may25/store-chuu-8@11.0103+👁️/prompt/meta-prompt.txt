# Meta-Prompt: GL-OS Refactor Handoff

## Current Goal
Refactor GL-OS by moving real code out of `gl_desktop.c` into TPMOS-style Ops so the monolith gets smaller, the render path becomes more auditable, and phase 3 markup work starts from a cleaner pipeline.

## What Phase 2 Is For
- Extract self-contained responsibilities from `gl_desktop.c` into independent Ops or standalone modules.
- Add a persistent logical/audit frame so rendering state can be checked without launching GL.
- Align the GL render path more closely with the ASCII-side TPMOS model: state first, drawing second.
- Preserve and formalize tree-based positioning for markup nodes so layout is hierarchical instead of ad hoc absolute math.
- Preserve the current behavior while refactoring, especially toolbar tab restore, minimize, active-window selection, terminal interaction, and project selection.

## What Phase 3 Is For
- Introduce HTML-like markup tags on top of the audited scene/pipeline.
- Treat the logical frame as the contract that markup rendering consumes.
- Render markup nodes through a tree/scene-graph style traversal with local positioning and clipping.
- Do not jump into phase 3 until phase 2 has a stable, file-backed audit pipeline.

## Baseline
- Use the clean pre-bug desktop source at `1.TPMOS_c_+rmmp.0100.0106+pre[]+1/pieces/apps/gl_os/plugins/gl_desktop.c`.
- Treat the current prompt docs `explainer.txt` and `phase2.txt` as the short handoff for the new context.

## Operating Rules
- Reduce LOC by moving code out of `gl_desktop.c`, not by rewriting everything at once.
- Prefer file-backed state and marker files over hidden in-memory state.
- Keep the logical audit frame easy to inspect with `cat`.
- Keep `gl_desktop.c` working during the transition; do not break existing GL-OS behavior to chase architecture.

## Stop Conditions
- If a refactor threatens tab restore, minimize, active window ordering, terminal behavior, or project selection, stop and isolate the change.
- If a change is only about phase 3 markup or deeper scene-graph cleanup, defer it until phase 2 is stable.
