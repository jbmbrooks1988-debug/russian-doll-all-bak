Codex local rollback archive policy

This project does not use git. Before Codex edits existing files, Codex should create
a timestamped archive batch under:

_codex_archives/YYYY-MM-DD/EPOCH/

Each batch should include:

- MANIFEST.txt describing the requested work and files archived
- copies of every existing file that will be edited, preserving relative paths

New files do not need pre-edit copies, but the batch manifest should list them.

Rollback rule:
To roll back a mistake, copy the archived file from the relevant epoch directory
back to its original relative path.
