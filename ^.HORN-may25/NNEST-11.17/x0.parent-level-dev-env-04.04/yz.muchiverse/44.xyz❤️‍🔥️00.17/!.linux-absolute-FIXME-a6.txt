======================================================================
0. POLICY (user directive 2026-08-06)
======================================================================

  **No path in this house should be absolute — not even on Linux.**

  That includes:
    - /home/no/Desktop/... tree roots
    - /media/no/<uuid> mountpoints (prefer relative or env-driven)
    - Any hard-coded machine-specific prefix

  Preferred form:
    - Paths relative to **house root** (the 44.xyz❤️‍🔥00.10 directory), OR
    - Paths relative to the **entity / package dir** when that is the
      natural CWD (KHTPM package_dir argument, event_pkg local), OR
    - Env vars resolved at runtime (HOUSE_ROOT, PRISC_PROJECT_ROOT, etc.)
      with **relative defaults** in registries — never baked abs paths.

  Runtime may *resolve* to absolute paths internally (getcwd, realpath,
  GetFullPathName) — that is fine. **Committed config / PDL / scripts
  must not store machine-absolute paths.**

  Why this matters for Windows port:
    - Linux abs paths are dead on Windows and on any other clone/move.
    - Emoji / long Desktop prefixes break CreateProcessA, PATH, CWD.
    - 014.wsr already proved relative roots + spawn-from-project-dir work.

======================================================================

  1. Confirm HOUSE_ROOT = directory containing $.crypts, &.widgits,
     #.desktop, @.apps (this tree's 44.xyz❤️‍🔥00.10).

  2. Mechanical replace of the Linux prefix:
       OLD = /home/no/Desktop/🤖️⬛️.../44.xyz❤️‍🔥00.10
       NEW =   (empty — leave relative remainder)
     Careful: some strings are quoted multi-arg shell lines; preserve
     quoting. Some are MOUNT mountpoints under /media/no/ — handle
     separately (env or skip mount on non-Linux).

  3. Ensure launchers resolve relative paths:
       - crypt_autostart: if LAUNCH value does not start with / or drive,
         prefix with resolved house root (or chdir house first).
       - button.sh / future button.ps1: always start from house root.
       - KHTPM already receives package_dir as argv — pass relative
         and chdir, or resolve once at start and keep internal abs.

  4. Windows note (for same agent or Win port agent):
       Relative paths must use `/` or native `\` consistently; MSYS
       often accepts `/`. Prefer forward slashes in PDL. Binaries:
       . +x on Linux vs .exe on Win — may need dual LAUNCH rows or
       platform suffix substitution in crypt_autostart (see
       khtpm-win-fix.txt). **Still relative, never absolute.**

  5. Verify:
       grep -rn '/home/no/' --include='*.pdl' --include='*.sh' \
         $.crypts #.desktop @.apps
       # expect zero hits in those trees after P0–P3
       Then boot: $.crypts/button.sh run  (Linux) or planned button.ps1

  6. Do **not** reintroduce absolute paths when generating new
     meta.pdl / methods.pdl / objects.pdl / autostart rows.
