PHASE 2: "hide/show" Option (MORE COMPLEX)
────────────────────────────────────────────────────────────────

✓ What it does:
  • Toggle: Hide ALL active desk-pals (entity windows)
  • Toggle: Restore ALL desk-pals (make visible again)
  • State persists across toggles (remember what was open)

✓ Challenge: How do we hide/restore entity windows?

  Option A: Send SIGSTOP/SIGCONT to entity processes
    Pros: Simple, preserves state in memory
    Cons: Windows disappear (processes frozen), may confuse WM

  Option B: Use X11 to unmap/map windows
    Pros: Windows go off-screen cleanly, WM aware
    Cons: More complex, needs XQueryTree + XUnmapWindow

  Option C: Close ALL entity windows + cache state
    Pros: Explicit and clear
    Cons: Loses state (scroll position, selection, etc)

  RECOMMENDATION: Option A (SIGSTOP/SIGCONT)
    • Simplest implementation
    • Preserves full state in process memory
    • Unix standard mechanism
    • Visual: windows "freeze" (acceptable for hide/show toggle)

✓ Implementation approach:

  CREATE: $.crypts/scripts/hide-show-desks.sh
    #!/bin/bash
    STATE_FILE="$HOME/.cache/muchiverse-desk-visibility"
    HOUSE="$(cd "$(dirname "$0")/../.." && pwd)"

    # Read livedesk_open.txt to get all entity PIDs
    OPEN_FILE="$HOUSE/#.desktop/livedesk_open.txt"

    if [ -f "$STATE_FILE" ] && [ -s "$STATE_FILE" ]; then
        # Visible → Hidden: freeze all
        grep "^PID=" "$OPEN_FILE" | awk -F= '{print $2}' | while read pid; do
            kill -STOP "$pid" 2>/dev/null
        done
        rm "$STATE_FILE"
        echo "🙈 All desk-pals hidden"
    else
        # Hidden → Visible: unfreeze all
        grep "^PID=" "$OPEN_FILE" | awk -F= '{print $2}' | while read pid; do
            kill -CONT "$pid" 2>/dev/null
        done
        echo "1" > "$STATE_FILE"
        echo "👁️  All desk-pals visible"
    fi

  UPDATE: ./#.desktop/livedesk_taskbar.pdl
    SECTION | hq_menu_3_label | hide/show
    SECTION | hq_menu_3_cmd   | sh $.crypts/scripts/hide-show-desks.sh

  Renumber X.quit and cancel rows accordingly

✓ State tracking:
  • File: $HOME/.cache/muchiverse-desk-visibility
  • Presence = visible, Absence = hidden
  • Survives session restart (user preference persists)

✓ Alternative: Use a database file in #.desktop/
  Better if we want persistence across reboots:
    #.desktop/livedesk_desk_visibility.txt
    Content: "hidden" or "visible"
  Pros: Stays with house, not tied to $HOME
  Cons: Needs cleanup code

RISKS & MITIGATION
════════════════════════════════════════════════════════════════

Risk: SIGSTOP freezes windows visibly (not truly "hidden")
  → Mitigation: Document as "Freeze/Unfreeze" in help text
  → User expectation: apps pause, don't disappear

Risk: User confusion about window state
  → Mitigation: Show feedback message ("🙈 hidden" / "👁️ visible")
  → Option: Add visual indicator in taskbar when desks are frozen

Risk: Entity windows don't handle SIGSTOP/CONT gracefully
  → Mitigation: Start with testing, add error handling in script
  → Fallback: If issues arise, switch to Option C (close/reopen)

Risk: livedesk_open.txt changes during iteration
  → Mitigation: Read file fresh on each toggle (already in script)
