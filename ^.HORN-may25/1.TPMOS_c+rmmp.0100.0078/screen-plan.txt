# GL-OS Window Control Buttons Plan

## Goal
Implement "- [] x" buttons for every window in the GL-OS virtual desktop to support:
1.  **Minimize (-)**: Hides the window from the desktop (restorable from the toolbar).
2.  **Half Screen ([])**: Toggles window between Left Half, Right Half, and Restore.
3.  **Full Screen/Maximize (x)**: Toggles window between Full Desktop and Restore.
    *(Note: Re-evaluating 'x' as Full Screen vs Close. Usually 'x' is close. Plan will add 'Maximize' button and keep 'Close')*

## Revised Button Mapping
To follow standard UX while meeting the "- [] x" request:
- **[-]** : Minimize (Existing: `_`)
- **[H]** : Half Screen (New: Toggles Left/Right/Restore)
- **[ ]** : Maximize (New: Toggles Full/Restore)
- **[X]** : Close (Existing: `X`)

## Implementation Steps

### 1. Update `DesktopWindow` Struct
Add fields to store the state before resizing/maximizing:
```c
typedef struct {
    ...
    int prev_x, prev_y, prev_w, prev_h;
    int is_maximized;
    int is_half_screen; /* 0=None, 1=Left, 2=Right */
    ...
} DesktopWindow;
```

### 2. Update `draw_window` in `gl_desktop.c`
- Adjust spacing in the title bar for 4 buttons.
- Draw the new "Half" and "Maximize" buttons.
- Use symbols: `-`, `H`, `[]`, `X`.

### 3. Implement Toggle Logic
Create helper functions:
- `void maximize_window(DesktopWindow* win)`
- `void half_screen_window(DesktopWindow* win)`
- `void restore_window(DesktopWindow* win)`

### 4. Update Mouse Input Handling
- In `mouse()` function, add hit detection for the new buttons.
- Handle clicks to trigger the toggle logic.

### 5. Taskbar Interaction
- Ensure that clicking a minimized window in the taskbar restores it to its previous state (even if it was maximized or half-screen).

## Visual Layout (Titlebar)
`[ Window Title                   ] [-] [H] [[]] [X]`
- Spacing: Buttons are 18x18 pixels.
- Gap: 4 pixels between buttons.
- Colors:
  - Close: Red
  - Maximize: Green
  - Half: Yellow
  - Minimize: Orange/Gold
