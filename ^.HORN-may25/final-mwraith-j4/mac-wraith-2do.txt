# WRAITH ARCHITECTURAL BLUEPRINT (PHASE J5)

## 1. THE VISION: Sovereign Map Desktop
Wraith is a **Map-Composer** project that orchestrates an ASCII desktop shell. 
It mirrors the window management of `gl_desktop.c` but implements it using the `fuzz-op` sovereign map standard.

- **Theater:** Standard CHTPM (Host).
- **Project:** Wraith PM (The "Map").
- **Entities:** Windows (Pieces) with $x, y, z, focused$ in `windows_state.pdl`.
- **Cursor:** The "Mousehand" (+) tracking mouse coordinates on the map.

## 2. COMPONENT ARCHITECTURE

### A. The Orchestrator (`wraith-pm_manager.c`)
- **Pipeline:** Trigger -> Wait -> Pulse.
- **Input Loop:** Polls `session/history.txt` at 60fps.
- **Commands:**
  - `MOUSE_MOVE x y`: Updates `mouse_x/y` in `state.txt`.
  - `wraith-pm::down`: Hit tests via `hitmap.pdl`. If titlebar, `SET drag_active true`.
  - `wraith-pm::up`: `SET drag_active false`.
  - `wraith-pm::nav N`: Moves `>` selector and SNAPS `mouse_x/y` to target.
- **Logic:**
  - `spawn_window(project_id)`: Adds entry to `windows_state.pdl`.
  - `close_window(id)`: Removes entry from `windows_state.pdl`.
  - `raise_z(id)`: Moves ID to the bottom of `windows_state.pdl` (Last drawn = Top).

### B. The Composer (`wraith_composer.c`)
- **Responsibility:** Deterministic frame generation from PDL state.
- **Logic:**
  1. Clear 96x30 grid.
  2. Draw Terrain (Desktop background, Taskbar).
  3. Draw Windows: Iterate `windows_state.pdl`.
     - Draw chrome (Titlebar with `[x]` and `[-]`, Borders).
     - Clip and draw content from `window_id.view.txt`.
  4. Draw "Mousehand" (+) at `mouse_x/y`.
- **Artifacts:** Writes `manager/view.txt` (Composed Frame) and `hitmap.pdl`.

### C. The Bridge (`desktop.chtpm`)
- **Wrapper:** `<panel><module>${module_path}</module><text label="${game_map}" /></panel>`
- **Sync:** Uses `${game_map}` magic variable to pull `manager/view.txt` without flattening.
