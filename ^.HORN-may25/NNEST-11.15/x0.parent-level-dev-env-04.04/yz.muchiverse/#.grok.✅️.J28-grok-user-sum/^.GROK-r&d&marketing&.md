## 🧬 1. Current ability — what the infrastructure already *is*

### 1.1 The spine (why it's different)

| 🧩 Layer | What it does | Why it innovates |
|----------|--------------|------------------|
| 📜 **CHTPM layouts** | Declarative menus / chrome in plain files | Designers edit UI without recompiling the universe |
| ⚙️ **Ops (+x)** | One verb = one binary, no shared-header tar pits | Swap gameplay like LEGO; agents can author ops |
| 🧵 **PAL / prisc+x** | Tiny VM loop, file-mediated IPC | Debuggable by reading disk; multi-process by design |
| ⌨️ **Keyboard bus** | `KEY_PRESSED: N` + history files | Terminal *and* GL share one input truth |
| 🖼️ **`chtpm_rgb_render`** | CPU raster of frame text + emoji tiles | Portable pixels — **no game code calls GL** |
| 🪞 **`gl_mirror` only** | Sole GL/GLUT citizen (governing constraint) | RISC-V / headless / swap backends without rewriting games |
| 🪟 **Widgets** | board-viewer, event-ez, file-menu, taskbar… | Product surface area without forking the engine |
| 🐧🪟 **Linux primary · Win shims** | `button.ps1`, host_fopen, CreateProcessW | Ship desk toys to the mass OS without dual product trees |

### 1.2 Live product surface (already in the house)

- 🧟 **mutaclsym** — all-in-one survival-ish CHTPM + emoji map + GL mirror  
- 🧱 **aomorai / piececraft** — seeded worlds, multi-Z chunks, **board-viewer** 2D/3D widget  
- 🐉 **MUCHI_RANCHER / KHTPM desk** — entity windows, RMB menus, livedesk taskbar  
- 📈 **yahoo-app** — bank GUI + broker widget pattern (separate programs, shared state files)  
- 🌾 **my-chara / my-biotech / my-lawyer** — vertical "life sims" on the same chassis  
- 📚 **book-stack / bible assets** — portable asset roots for Win desks  
- 🧩 **014.wsr-pal** — canonical Win freeglut vertical (donor PE for the family)

### 1.3 Agent-native superpower 🤖

Because **state is files**, an agent (or intern) can:

1. 📖 Read `current_frame.txt` / receipts instead of guessing pixels  
2. ✍️ Inject keys into `history.txt` for harnesses  
3. 🧪 Diff checksums on `rgb_frame.raw` after a change  
4. 🔁 Port a fix once (e.g. Win `rename` freeze, MAP3D black map) across apps  

This is **R&D velocity as a product feature**, not a private CI trick.

### 1.4 Innovation thesis (one sentence)

> 🎯 **We industrialize playful software by making process, UI, and assets file-mediated and therefore agent-operable.**
