## Architecture

- Main app (`@.apps/yahoo-app/`) runs bank GUI in foreground with its own GL window
- Broker widget (`&.widgits/yahoo-broker/`) spawns on demand via `OPEN_BROKER_WIDGET` using `setsid` (same pattern as `OPEN_BOARD_WIDGET` in civ-txt/tactics-txt)
- State shared via files: `usr_acc.<hash>.txt` for account, `broker_state.txt` for broker balance, `config.txt` for bank balance
- Broker list is dynamic `${piece_methods}` generated from `brokers.txt`
