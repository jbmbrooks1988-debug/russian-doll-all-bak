🔺️👩🏻‍🔬️⚛️🔺️# 🧪 Welcome to the Element Crafting System! 🚀

Hey there, chemistry wizard! 🧙‍♂️ Ready to craft some awesome compounds like `Hydrogen`, `Water`, or even your own wild creations? 🎉 This guide will teach you how to read and write the `elements.txt` file, just like the `craft.c` program does, so you can build your own chemical masterpieces! 🌟

## 📜 What is `elements.txt`?

The `elements.txt` file is the heart of the crafting system. 💖 It lists all the elements and compounds you can craft, along with their properties and how to make them. The program reads this file to figure out what you can create with your inventory. 🧳 Here's how it works!

### 🔍 File Format

Each line in `elements.txt` describes one element or compound. It has **six fields** separated by spaces:

```
Name Protons Neutrons Electrons Combo1 Combo2
```

- **Name** 🏷️: The element's name (e.g., `Hydrogen`, `Water`, `MyCoolCompound`). Max 19 characters, no spaces!
- **Protons** ⚛️: Number of protons (e.g., `1` for `Hydrogen`). Use `-1` for fictional elements.
- **Neutrons** 🟠: Number of neutrons. Use `-1` for fictional elements.
- **Electrons** ⚡️: Number of electrons. Use `-1` for fictional elements.
- **Combo1** 🔗: Index of the first element needed to craft this one (e.g., `5` for `Proton`).
- **Combo2** 🔗: Index of the second element needed to craft this one (e.g., `2` for `Electron`).

**Example**:
```
Hydrogen 1 0 1 5 2
Helium 2 2 2 5 6
Proton 1 0 0 3 1
Electron 0 0 1 -1 -1
Water 10 8 10 121 14
```

- `Hydrogen` needs `Proton` (index 5) and `Electron` (index 2).
- `Water` needs `Moscovium` (index 121) and `Oxygen` (index 14).
- `Electron` has `Combo1=-1`, `Combo2=-1`, meaning it can't be crafted (base element).

## 🧠 How the Program Reads It

The `craft.c` program loads `elements.txt` like this:

1. **Reads Lines** 📖: Opens `elements.txt` and reads each line.
2. **Parses Fields** ✂️: Uses `sscanf` to split each line into `name`, `protons`, `neutrons`, `electrons`, `combo1`, `combo2`.
3. **Stores Elements** 🗃️: Saves each element in arrays (e.g., `element_names`, `element_combo1`).
4. **Assigns Indices** 🔢: The order in the file determines the index (e.g., `Up_quark` is index 0, `Electron` is 2).
5. **Crafting Check** 🔍: When you run `!craft`, it checks your inventory for `Combo1` and `Combo2` elements to make the target.

**Example**:
- To craft `Hydrogen` (index 7), you need `Proton` (index 5) and `Electron` (index 2) in your inventory.
- If you try `!craft @_i___l__ Hydrogen` but lack `Proton`, it says: `Craft failed: cannot craft Hydrogen. Your inventory: Up_quark, Down_quark, Hydrogen To craft Hydrogen, you need: Proton, Electron (Proton (1 more), Electron (1 more))`.

## 🛠️ How to Create Your Own Compounds

Want to add your own epic compound like `SuperMolecule`? 🌈 Follow these steps:

1. **Open `elements.txt`** 📝:
   - Find `data/elements.txt` in your project folder.
   - Open it in a text editor (like Notepad or VS Code).

2. **Add Your Compound** ➕:
   - Add a new line with six fields: `Name Protons Neutrons Electrons Combo1 Combo2`.
   - **Name**: Choose a unique name (e.g., `SuperMolecule`).
   - **Protons/Neutrons/Electrons**: Use realistic numbers or `-1` for fictional compounds.
   - **Combo1/Combo2**: Pick the indices of two elements in `elements.txt` that combine to make your compound.

3. **Find Indices** 🔎:
   - The index is the line number (starting at 0) of the element in `elements.txt`.
   - Example: If `Carbon` is on line 13, its index is 12 (0-based).
   - Use `-1` for `Combo1` and `Combo2` if the element can’t be crafted (like `Electron`).

4. **Example Entry**:
   ```
   SuperMolecule -1 -1 -1 12 14
   ```
   - Crafts `SuperMolecule` using `Carbon` (index 12) and `Oxygen` (index 14).
   - Use `-1 -1 -1` for fictional properties.

5. **Save and Test** 💾:
   - Save `elements.txt`.
   - Run `!craft @_i___l__ SuperMolecule` with `Carbon` and `Oxygen` in your inventory.
   - If you don’t have them, it’ll tell you what’s missing!

## ⚠️ Tips and Warnings

- **Valid Indices** ✅: Ensure `Combo1` and `Combo2` are valid indices (0 to `element_count-1`) or `-1`. Check the line order in `elements.txt`!
- **No Spaces in Names** 🚫: Names like `Super Molecule` will break parsing. Use `SuperMolecule` or `Super_Molecule`.
- **Unique Names** 🔑: Don’t reuse names (e.g., two `Hydrogen` entries confuse the program).
- **Inventory Check** 🧳: Make sure your `chems.txt` has the elements listed in `Combo1` and `Combo2`.
- **Order Matters** 📋: The program assigns indices based on the order in `elements.txt`. Add new compounds at the end to avoid shifting indices.
